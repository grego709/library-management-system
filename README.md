
# Library Management System

## Project Description
A simple Library Management System developed using PHP, MySQL, HTML, CSS and JavaScript.

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- phpMyAdmin
- XAMPP

## Main Features
- Add and manage books
- Register library members
- Issue books to members
- Return borrowed books
- View borrowing records
- Search for books
- Dashboard statistics

## Database Tables
1. books
2. members
3. borrow_records

## Installation
1. Install XAMPP.
2. Copy the project folder into htdocs.
3. Start Apache and MySQL.
4. Import database.sql using phpMyAdmin.
5. Configure db.php.
6. Open http://localhost/library_system/
